# Task 7: Sales Summary using SQLite and Python

This project connects a Python script to an SQLite database and performs a simple sales analysis.

## Tools Used
- Python
- SQLite
- Pandas
- Matplotlib

## Steps Performed
1. Connected to `sales_data.db`
2. Queried total quantity and revenue per product using SQL
3. Loaded results into pandas DataFrame
4. Plotted a bar chart of revenue by product

## Output
- `sales_chart.png` visualizing product-wise revenue
